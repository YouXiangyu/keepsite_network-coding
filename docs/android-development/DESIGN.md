# keepsite Android 界面设计规范

创建日期：2026-10-24。更新日期：2026-10-26。

本规范约束 `android/` 原生客户端的视觉与交互。视觉语言参考 `docs/UI_example` 的两张图（电影收藏页、“我的”页）：白底、图片主导、紧凑的大标题、浅灰搜索框、轻量卡片与底栏。参考图只提供视觉风格；功能范围以 [项目定义与决策主文档](../项目定义与决策主文档.md) 为准，不引入探索、朋友分享、分类等已删除业务。

代码中的唯一取值来源：

| 内容 | 位置 |
| --- | --- |
| 颜色 | `android/app/src/main/res/values/colors.xml` |
| 字号、间距、圆角、尺寸 | `android/app/src/main/java/io/github/youxiangyu/keepsite/ui/Design.kt` |
| 文字、按钮、输入框、卡片、列表行等组件 | `android/app/src/main/java/io/github/youxiangyu/keepsite/ui/Widgets.kt` |
| 对话框圆角与按钮文字 | `android/app/src/main/res/values/themes.xml`（`ThemeOverlay.keepsite.Dialog`） |
| 底栏背景圆角 | `android/app/src/main/res/drawable/navigation_background.xml` |
| 图标 | `android/app/src/main/res/drawable/ic_*.xml`，描边颜色引用 `@color/mv_ink` / `@color/mv_muted` |

页面代码只调用组件和 `Design` 常量，不直接写字号、圆角或颜色值。XML 资源无法引用 Kotlin 常量，上表列出的 XML 位置须与本规范取值保持一致。新增样式时先更新本规范和 `Design.kt`，再使用。

## 1. 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| `mv_background` | `#FFFFFF` | 页面与面板背景 |
| `mv_ink` | `#202124` | 主文字、主按钮底色、选中图标 |
| `mv_muted` | `#656B76` | 次要文字、提示、未选中图标；与白色、`mv_soft` 对比度均 ≥ 4.5:1 |
| `mv_soft` | `#F3F3F4` | 搜索框、输入框、次按钮、图片占位 |
| `mv_line` | `#E9E9EC` | 面板描边与分隔线 |
| `mv_accent` | `#58695D` | 开关、在线等正常状态的点缀色，不用于大面积背景 |
| `mv_error` | `#A6343C` | 错误文字、删除等危险操作 |
| `mv_error_soft` | `#FBEEEF` | 错误提示条与危险按钮底色 |
| `mv_primary` | `#262925` | 仅作为主题 `colorPrimary`，供系统控件默认取色；页面组件不直接使用 |

- 整体保持中性灰白，颜色主要来自电影封面。不新增渐变、彩色大块背景或装饰色。
- 状态不能只靠颜色表达，必须同时有文字。

## 2. 字体与字号

使用系统无衬线字体（中文跟随系统 CJK 字体），不打包自定义字体。字号单位为 sp，随系统字体缩放。

| 层级 | 字号 | 字重 | 行距倍数 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 28 | Bold | 1.15 | 页面大标题：电影、我的、欢迎回来、同步与设备；“我的”页头像首字母 |
| Title | 20 | Bold | 1.2 | 区块标题：最近添加、按月回看、本机图片缓存；“我的”页账号名 |
| Subtitle | 16 | Medium | 1.25 | 卡片片名、列表行标题、设备名、月份名 |
| Body | 15 | Regular | 1.35 | 正文、字段值、输入内容 |
| Label | 13 | Medium | 1.3 | 表单字段名、信息行名称、最近添加缩略图片名、“我的”页统计行 |
| Caption | 12 | Regular | 1.3 | 日期、数量、缓存与云存状态等辅助信息 |
| Button | 16 | Medium | 1.0 | 实底按钮文字 |
| TextButton | 15 | Medium | 1.0 | 文字按钮；行内小操作（如“清除放映时间”）可用 Label |
| Nav | 11 | Medium | 1.0 | 底栏标签 |

- 一屏最多一个 Display 标题。
- 层级靠字号和字重区分，同一区域不混用两种以上的灰色。
- 文字不全大写；片名最多两行，超出用省略号。

## 3. 间距

以 4dp 为网格，只使用下列值：

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `xs` | 4dp | 图标与文字、片名与日期 |
| `s` | 8dp | 同组元素之间 |
| `m` | 12dp | 输入框之间、卡片网格间隙、面板内行距 |
| `l` | 16dp | 面板内边距、按钮组间距 |
| `page` | 20dp | 页面左右边距 |
| `xl` | 24dp | 区块之间 |
| `xxl` | 32dp | 页面底部留白、大区块分隔 |

## 4. 圆角

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `photo` | 4dp | “按月回看”的相纸边框与其中照片 |
| `image` | 10dp | 票夹网格中的封面、“最近添加”缩略图 |
| `control` | 12dp | 输入框、按钮、信息条 |
| `panel` | 16dp | 面板、详情大图、录入票面预览 |
| `sheet` | 22dp | 底栏顶部圆角 |
| `pill` | 高度的一半 | 搜索框、头像、底栏“录入”圆形按钮 |

同一页面不出现其他圆角值。

## 5. 尺寸与触达

- 所有可点击元素触达区域至少 48dp × 48dp；搜索框高度 48dp。
- 输入框高 52dp，按钮高 52dp（文字按钮 48dp）。
- 图标统一 24dp 视觉尺寸，线宽 1.8，圆头圆角。例外：列表行右箭头、搜索放大镜、日期图标等指示图标为 20dp；空白预览区中央占位图标为 36dp。
- 底栏每项高至少 56dp；“录入”按钮为 48dp 圆形。底栏带 12dp elevation 的轻阴影，与内容分层。
- 头像 56dp 圆形，显示账号首字母；“我的”页顶部头像为 80dp。
- “最近添加”缩略图宽 112dp，统一 3:4 居中裁切，横向滚动并贴到屏幕右缘；“按月回看”相纸堆叠区高 168dp，前后两张相纸各倾斜 2°/4°，带 3dp elevation 轻阴影。这两处只是预览，完整票面仍在票夹和详情中不裁切显示；缩略图按长边 640px 解码。
- 录入页未选择票面时，预览区高 220dp；已有图片时按图片比例显示，高度限制在 80–420dp。
- 容量进度条粗 6dp，两端为半圆。
- 登录、详情、录入、“我的”及其次级页面等纵向页面的内容最大宽度 640dp，在横屏和平板上水平居中；票夹网格不受此限，按最小列宽 156dp（随字体放大）自适应列数。

## 6. 组件

**按钮**（`action(text, kind)`）

| 类型 | 外观 | 用法 |
| --- | --- | --- |
| Primary | `mv_ink` 实底、白字 | 每屏最多一个：登录、保存电影票、编辑电影票 |
| Secondary | `mv_soft` 实底、`mv_ink` 字 | 次要操作：选择票面、展开原始票面、Google 登录 |
| Text | 无底色、`mv_ink` 字 | 取消、重新加载、查看链接 |
| Quiet | 无底色、`mv_muted` 字和图标 | 弱化的导航与辅助操作：返回、登录页模式切换、清除放映时间 |
| Danger | `mv_error_soft` 底、`mv_error` 字 | 删除电影票等不可撤销操作；仍需确认对话框 |

- 按钮无阴影、不全大写，文字居中；禁用时整体降到 40% 不透明度。例外：放映时间选择器外观与输入框一致，文字左对齐，日历图标在右。

**输入框**（`input(hint)`）：`mv_soft` 实底、12dp 圆角、无下划线，左右内边距 16dp，字号 Body；禁用时与按钮一样降到 40% 不透明度。字段名用 Label 层级放在输入框上方 8dp。

**面板**（`panel()`）：白底、1dp `mv_line` 描边、16dp 圆角、无阴影；左右内边距 16dp，上下 8dp（信息行自带上下 12dp）。纯文字内容的面板上下改用 16dp。用于把同一主题的信息分组。

**信息行**（`infoRow(name, value)`）：左侧 Label 灰字固定宽度，右侧 Body 黑字；行间用 `mv_line` 分隔线。

**列表行**（`listRow(icon, title)`）：图标 + 标题 + 右箭头，高度至少 52dp，无障碍角色为按钮，用于“我的”页入口和次级页面中的操作；危险项文字和图标用 `mv_error`。

**提示条**：普通提示用 `mv_soft` 底 + `mv_muted` 字；错误用 `mv_error_soft` 底 + `mv_error` 字；12dp 圆角，内边距左右 12dp、上下 8dp，位于内容区上方，左右距屏幕边缘 20dp（宽屏下不随内容区居中）。

**对话框**：Material 对话框，16dp 圆角，按钮为 `mv_ink` 文字按钮。

## 7. 页面结构

- **页面骨架**：顶部为页面大标题（Display），其下依次是工具区、内容区。左右边距 20dp，底部留白 32dp。
- **票夹**：标题“电影” + 右侧数量；排序文字按钮带下箭头图标，右侧刷新图标按钮；浅灰圆角搜索框；自适应列数的错落网格，封面保持原比例不裁切，下方片名（Subtitle）与日期（Caption）。
- **按月票夹**：从“按月回看”进入；左上“‹ 我的”返回，标题为月份（如“2026年10月”）+ 当月数量，网格同票夹，不显示排序、搜索。
- **详情**：左上返回到来源页（“‹ 票夹”“‹ 我的”或月份）；片名大标题；16dp 圆角大图；“票面信息”“保存状态”两个面板；主按钮“编辑电影票”，危险按钮“删除电影票”放在最后。
- **录入**：标题与一句说明；票面预览区 + 次按钮“选择或替换票面”；带字段名的输入框；放映时间用与输入框同样式的选择器；底部主按钮“保存电影票”和文字按钮“取消”。
- **我的**：标题“我的”；80dp 头像 + 账号名（Title）+ 邮箱；统计行“N 张电影票 · M 个观影月份”；“最近添加 ›”（点击进入票夹）+ 最近 10 张横向缩略图；“按月回看”双列相纸卡片，最多最近 6 个月，按放映时间分月，未填放映时间按添加时间；最后是“账户与登录 / 同步与设备 / 关于与隐私”三行入口面板。没有电影票时以一句灰字代替两个图片区。
- **次级页面**：左上“‹ 我的”返回 + Display 标题。“账户与登录”：账号头像与邮箱、“登录方式”面板、“退出”危险列表行。“同步与设备”：“本机图片缓存”面板（数量、容量进度条、清空入口）、“设备间传输”面板（开关、状态、在线设备）、“最近传输”、“刷新状态”列表行。“关于与隐私”：TMDB 海报数据说明。
- **登录**：顶部品牌标识（票夹图标 + Subtitle“我的票夹”，仅未登录时显示）、大标题与一句说明；输入框；主按钮；Google 登录为次按钮，与邮箱登录之间用“或”分隔线；模式切换为两列 Quiet 按钮。
- **底栏**：白底，顶部 22dp 圆角；三个入口“票夹 / 录入 / 我的”；图标 24dp + 11sp 标签居中，选中为 `mv_ink` 实心图标、加粗标签，未选中为 `mv_muted` 线框图标；详情、按月票夹和次级页面高亮其来源入口；中间“录入”为 48dp `mv_soft` 圆形按钮。键盘弹出时隐藏。

## 8. 可访问性与状态

- 灰字对比度不低于 4.5:1（已有仪器测试检查 `mv_muted`）。
- 图标按钮必须有 `contentDescription`；页面标题设为无障碍标题。
- 加载、失败、未云存、临时查看等真实状态必须可见，不能为美观隐藏；正常的“已缓存”提示在网格中可以收起。
- 支持系统字体放大：网格最小列宽随字体缩放增加，文字不截断关键信息。
