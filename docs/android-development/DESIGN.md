# MemoVerse Android 界面设计规范

创建日期：2026-10-24。更新日期：2026-10-24。

本规范约束 `android/` 原生客户端的视觉与交互。视觉语言参考 `docs/UI_example` 的四张图：白底、图片主导、紧凑的大标题、浅灰搜索框、轻量卡片与底栏。参考图只提供视觉风格；功能范围以 [项目定义与决策主文档](../项目定义与决策主文档.md) 为准，不引入探索、朋友分享、分类等已删除业务。

代码中的唯一取值来源：

| 内容 | 位置 |
| --- | --- |
| 颜色 | `android/app/src/main/res/values/colors.xml` |
| 字号、间距、圆角、尺寸 | `android/app/src/main/java/io/github/youxiangyu/memoverse/ui/Design.kt` |
| 文字、按钮、输入框、卡片、列表行等组件 | `android/app/src/main/java/io/github/youxiangyu/memoverse/ui/Widgets.kt` |

页面代码只调用组件和 `Design` 常量，不直接写字号、圆角或颜色值。新增样式时先更新本规范和 `Design.kt`，再使用。

## 1. 颜色

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| `mv_background` | `#FFFFFF` | 页面与面板背景 |
| `mv_ink` | `#202124` | 主文字、主按钮底色、选中图标 |
| `mv_muted` | `#656B76` | 次要文字、提示、未选中图标；与白色、`mv_soft` 对比度均 ≥ 4.5:1 |
| `mv_soft` | `#F3F3F4` | 搜索框、输入框、次按钮、图片占位 |
| `mv_line` | `#E9E9EC` | 面板描边与分隔线 |
| `mv_accent` | `#58695D` | 开关、在线等正常状态的点缀色，不用于大面积背景 |
| `mv_error` | `#A6343C` | 错误文字、删除等危险操作 |
| `mv_error_soft` | `#FBEEEF` | 错误提示条与危险按钮底色 |

- 整体保持中性灰白，颜色主要来自电影封面。不新增渐变、彩色大块背景或装饰色。
- 状态不能只靠颜色表达，必须同时有文字。

## 2. 字体与字号

使用系统无衬线字体（中文跟随系统 CJK 字体），不打包自定义字体。字号单位为 sp，随系统字体缩放。

| 层级 | 字号 | 字重 | 行距倍数 | 用途 |
| --- | --- | --- | --- | --- |
| Display | 28 | Bold | 1.15 | 页面大标题：电影、欢迎回来、设备与缓存 |
| Title | 20 | Bold | 1.2 | 区块标题：海报来源、本机图片缓存 |
| Subtitle | 16 | Medium | 1.25 | 卡片片名、列表行标题、设备名 |
| Body | 15 | Regular | 1.35 | 正文、字段值、输入内容 |
| Label | 13 | Medium | 1.3 | 表单字段名、信息行名称 |
| Caption | 12 | Regular | 1.3 | 日期、数量、缓存与云存状态等辅助信息 |
| Button | 16 | Medium | 1.0 | 按钮文字；文字按钮可用 15 |
| Nav | 11 | Medium | 1.0 | 底栏标签 |

- 一屏最多一个 Display 标题。
- 层级靠字号和字重区分，同一区域不混用两种以上的灰色。
- 文字不全大写；片名最多两行，超出用省略号。

## 3. 间距

以 4dp 为网格，只使用下列值：

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `xs` | 4dp | 图标与文字、片名与日期 |
| `s` | 8dp | 同组元素之间 |
| `m` | 12dp | 输入框之间、卡片网格间隙、面板内行距 |
| `l` | 16dp | 面板内边距、按钮组间距 |
| `page` | 20dp | 页面左右边距 |
| `xl` | 24dp | 区块之间 |
| `xxl` | 32dp | 页面底部留白、大区块分隔 |

## 4. 圆角

| 名称 | 值 | 用途 |
| --- | --- | --- |
| `image` | 10dp | 票夹网格中的封面 |
| `control` | 12dp | 输入框、按钮、信息条 |
| `panel` | 16dp | 面板、详情大图、录入票面预览 |
| `sheet` | 22dp | 底栏顶部圆角 |
| `pill` | 高度的一半 | 搜索框、头像、底栏“录入”圆形按钮 |

同一页面不出现其他圆角值。

## 5. 尺寸与触达

- 所有可点击元素触达区域至少 48dp × 48dp；搜索框高度 48dp。
- 输入框高 52dp，按钮高 52dp（文字按钮 48dp）。
- 图标统一 24dp 视觉尺寸，线宽 1.8，圆头圆角；底栏“录入”按钮为 48dp 圆形。
- 头像 56dp 圆形，显示账号首字母。
- 登录、详情、录入、设备等纵向页面的内容最大宽度 640dp，在横屏和平板上水平居中；票夹网格不受此限，按最小列宽 156dp（随字体放大）自适应列数。

## 6. 组件

**按钮**（`action(text, kind)`）

| 类型 | 外观 | 用法 |
| --- | --- | --- |
| Primary | `mv_ink` 实底、白字 | 每屏最多一个：登录、保存电影票、编辑电影票 |
| Secondary | `mv_soft` 实底、`mv_ink` 字 | 次要操作：选择票面、展开原始票面、Google 登录 |
| Text | 无底色、`mv_ink` 字 | 模式切换、取消、清除、查看链接 |
| Danger | `mv_error_soft` 底、`mv_error` 字 | 删除电影票等不可撤销操作；仍需确认对话框 |

- 按钮无阴影、不全大写，文字居中；禁用时整体降到 40% 不透明度。

**输入框**（`input(hint)`）：`mv_soft` 实底、12dp 圆角、无下划线，左右内边距 16dp，字号 Body。字段名用 Label 层级放在输入框上方 8dp。

**面板**（`panel()`）：白底、1dp `mv_line` 描边、16dp 圆角、16dp 内边距、无阴影。用于把同一主题的信息分组。

**信息行**（`infoRow(name, value)`）：左侧 Label 灰字固定宽度，右侧 Body 黑字；行间用 `mv_line` 分隔线。

**列表行**（`listRow(icon, title)`）：图标 + 标题 + 右箭头，高度至少 52dp，用于设备页的操作入口；危险项文字用 `mv_error`。

**提示条**：普通提示用 `mv_soft` 底 + `mv_muted` 字；错误用 `mv_error_soft` 底 + `mv_error` 字；12dp 圆角，位于页面顶部，左右与页面边距对齐。

## 7. 页面结构

- **页面骨架**：顶部为页面大标题（Display），其下依次是工具区、内容区。左右边距 20dp，底部留白 32dp。
- **票夹**：标题“电影” + 右侧数量；排序文字按钮带下箭头图标，右侧刷新图标按钮；浅灰圆角搜索框；自适应列数的错落网格，封面保持原比例不裁切，下方片名（Subtitle）与日期（Caption）。
- **详情**：左上“‹ 票夹”返回；片名大标题；16dp 圆角大图；“票面信息”“保存状态”两个面板；主按钮“编辑电影票”，危险按钮“删除电影票”放在最后。
- **录入**：标题与一句说明；票面预览区 + 次按钮“选择或替换票面”；带字段名的输入框；放映时间用与输入框同样式的选择器；底部主按钮“保存电影票”和文字按钮“取消”。
- **设备与缓存**：账号头像与邮箱；“本机图片缓存”面板（数量、容量进度条、清空入口）；“设备间传输”面板（开关、状态、在线设备）；最后是“刷新状态”“退出”列表行。
- **登录**：品牌小字、大标题与一句说明；输入框；主按钮；Google 登录为次按钮；模式切换为两列文字按钮。
- **底栏**：白底，顶部 22dp 圆角；三个入口“票夹 / 录入 / 设备”；图标 24dp + 11sp 标签居中，选中为 `mv_ink`，未选中为 `mv_muted`；中间“录入”为 48dp `mv_soft` 圆形按钮。键盘弹出时隐藏。

## 8. 可访问性与状态

- 灰字对比度不低于 4.5:1（已有仪器测试检查 `mv_muted`）。
- 图标按钮必须有 `contentDescription`；页面标题设为无障碍标题。
- 加载、失败、未云存、临时查看等真实状态必须可见，不能为美观隐藏；正常的“已缓存”提示在网格中可以收起。
- 支持系统字体放大：网格最小列宽随字体缩放增加，文字不截断关键信息。
