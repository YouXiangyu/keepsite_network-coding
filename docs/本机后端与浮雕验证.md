# 本机后端与浮雕验证

日期：2026-10-15。本轮按用户最新授权在本机实现前后端分离，未 SSH、未部署远端。本文记录已完成的本机链路，不代表正式产品达到 95%。

## 实现范围

- 前端 `127.0.0.1:4173` 调用 FastAPI `127.0.0.1:8000`；元数据使用 SQLite，媒体保存在项目 D 盘目录。PostgreSQL 是原材料候选，非用户硬指定。
- 旧 IndexedDB 的 `current` 快照保留，通过稳定迁移标识执行一次性迁移；重试不覆盖后续修改，非空目标冲突不静默合并。
- 原图以原始字节落盘，使用 SHA-256 校验与去重。收藏新增、读取、编辑、删除，资料修改及示例社区、朋友内容的本地互动均通过真实 API 持久化；示例数据不代表远端社区活动。
- 图片保存后自动建立持久生成任务，记录状态和输入版本；服务不可用保留任务，恢复后继续。纯文字修改复用模型，换图产生新任务，旧结果不得覆盖新输入或复活已删除条目。

## 实际浮雕链路

采用 AnyImage 官方提交 `2e2ab3eb9b5242deadca097c929c40329dbb5012` 的 MoGe2 ONNX 推理，在本机 CPU 上执行；本项目将预测深度转换为浮雕网格，并导出带嵌入纹理的 GLB。详情页使用 Three.js 展示真实模型和纹理；本轮原验证时的整体偏转上限为 20°。

后续交互修订（D-040）：已改为从正面任意方向总偏转最多 40°，鼠标在哪个角落就压下哪个角落；左右方向保留，上下反向已修正。新增两项旋转回归检查通过，验证四边、四角的目标顶点远离相机，且组合角度不超过 40°；浏览器四边 hover 约 38.3–38.5°（测试点距边缘 2%），角落 hover 和按钮累加实测达到 40°。新构建与 28 项运行时完整性检查通过。下列记录仍保留原验证轮次的 20° 条件。

这条链路没有执行 Blender Bake Mesh，不将其描述为已完成该插件的完整 Blender 烘焙流程；卡片晃动也不作为真实浮雕生成的证明。实现见 `backend/anyimage_worker.py`，接口边界见[本机 API 实施约定](local-api-contract.md)。

## 验证记录

- 浏览器实际导入参考图裁切照片，保存后自动生成并显示真实浮雕。
- 暂停 API 后保存失败，草稿保留；恢复 API 后重试成功。
- 仅修改文字后模型 URL 保持不变。
- 后端重启、浏览器刷新后，原图与模型仍可重新打开。
- 从实际工作区导出 ZIP，逐字节校验原图及 GLB 与接口返回一致，确认包含深度产物；临时导出文件在下载完成后清理。
- 当前工作区保留旧 14 件收藏，并新增 1 件真实浮雕示例；数量是本轮验证时点快照。
- 原验证轮次：26 个后端测试、17 个前端/静态/角度检查通过；构建通过，28 项受保护运行时文件检查通过。其中角度检查基于当时 20° 规范，未改写为 40° 检查通过。

后端任务状态机测试使用微小假 GLB，覆盖成功、失败、重启恢复、服务阻塞与恢复、旧结果隔离和备份完整性；它们不证明模型质量。真实浮雕链路另经实际推理与浏览器展示验证。截图已保存为 `demo/qa/backend-relief.jpg`；本报告不以截图代替完整视觉验收。
