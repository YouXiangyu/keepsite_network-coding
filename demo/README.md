# 生活纪念品收藏 · 本地 demo

这是首轮五页交互 demo，用于逐页调整收藏首页、分类收藏、探索、朋友分享和我的。视觉依据为 `../docs/design-references/`，产品决定见 `../docs/项目定义与决策主文档.md`。当前不代表正式产品完成，也不代表达到 95%。

当前支持收藏详情、搜索、来源筛选、排序、按月回看、单图导入、新增与编辑收藏、删除、资料编辑，以及包含媒体文件的本机 ZIP 备份导出。前端通过本机 API 读写资源；操作成功后才更新界面并提示，失败保留表单草稿。标签未填写时交由服务端按历史名字与标签匹配，无匹配则留空。只区分来源，不增加想体验、已体验或打卡状态。

导入支持 JPG、PNG、WebP，单张上限 12 MiB。预览使用临时 Object URL，换图、离开表单和组件卸载时释放；提交以 multipart 上传原始 File，收藏记录引用服务端 assetId 与图片 URL。新建收藏必须选择真实图片，不能把预置演示图片当作新上传。每个新增草稿使用稳定 UUID，以便相同内容重试时不重复创建。

首次启动读取旧 IndexedDB：数据库 `memoverse-prototype`、对象仓库 `app-data`、键 `current`。原快照始终保留，只在同一仓库独立键 `api-migration` 中记录稳定迁移 ID 与已完成的 serverId。后端负责一次性导入旧记录及 Data URL 图片；相同迁移重试不覆盖之后的服务端修改。损坏快照和目标冲突会显示错误，不静默重置或合并；只有无旧数据且后端为空时才初始化示例数据。

浏览器存储按协议、主机和端口隔离；首次迁移必须沿用原来的前端地址。若此前使用 `localhost:4173`，不要改成 `127.0.0.1:4173` 后宣称旧数据不存在。迁移后，业务写入本机服务，旧 IndexedDB 只作迁移前备份。当前是单用户本机工作区，尚无正式账号隔离或云备份，导入图片不会自动公开。

探索中的社区内容、曝光、收藏和喜欢数，以及朋友分享中的人物与记录均为示例；互动保存到本机服务，榜单排序用于演示。预置主题不是已运行的远端推荐服务。真实图片保存后由服务端创建生成任务；前端在存在排队、处理或阻塞任务时每 4 秒查询状态，普通详情页每 10 秒查询，按 revision 忽略晚到旧响应。失败或服务未就绪时保留原图并显示原因，可手动重试。卡片 CSS 晃动只是图片预览，不能替代 AnyImage 输出；真实结果以任务 ready 和 modelUrl 为准。OCR、正式认证、云同步和 Android 原生近场传输不属于这次前端 API 接入的完成声明。

API 默认地址为 `http://127.0.0.1:8000`，可通过 `VITE_API_BASE_URL` 修改并重启前端。后端须允许实际前端 origin 的 CORS；无需修改受保护的 Vite 或静态 Worker 运行时。请求与响应约定见 `../docs/local-api-contract.md`。

本轮已接入真实浮雕：服务端使用 AnyImage 官方 MoGe2 深度推理及本项目网格/GLB 导出，详情页懒加载 Three.js 显示嵌入纹理的非平面网格。最新交互将偏离正面的总角度上限改为 40°，斜向也受同一总角度约束；鼠标在哪个角落，就压下哪个角落，上下反向已修正。四边及四角的旋转回归检查与浏览器交互验证已通过。不是 Blender Bake Mesh 操作。模型查看器按需绘制，离开页面释放 WebGL、几何和纹理资源。启动后端与依赖准备见 `../backend/README.md`，本轮验证见 `../docs/本机后端与浮雕验证.md`。

在本目录执行以下命令（需要支持 TypeScript 类型剥离参数的 Node.js）：

```powershell
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

本地预览地址为 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。保持这一主机与端口以读取此前数据；`--strictPort` 防止端口占用时自动切换到其他存储空间。开发服务和构建前会自动检查受保护的移动设备运行时。

构建与检查命令：

```powershell
npm run check:runtime
npm run build
node --test tests/data.test.mjs tests/api.test.mjs
npm run test:sites
```

测试命令使用 Node.js 24；API 单元测试用 Node 的解析 hook 加载前端 TypeScript，无需额外测试依赖。它验证迁移决策、接口失败和上传请求，不代替真实浏览器迁移与服务端集成测试。`test:sites` 检查构建后的静态 Worker 输出，不会发布站点。
